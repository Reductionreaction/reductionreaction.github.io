# wifi & SSH
这里如果没有屏幕，需要烧录系统后在rootfs中

- 创建wpa_supplicant.conf，然后写入

```bash
update_config=1
ap_scan=1
fast_reauth=1
country=CN
network={
	ssid="要连接的WiFi1 名字"
	psk="要连接的WiFi1 密码"
	priority=5
}
network={
	ssid="要连接的WiFi2 名字"
	psk="要连接的WiFi2 密码"
	priority=4
}
```

# Samba服务

<font size = 5 font color = purple>**树莓派/服务器中**</font>

```bash
sudo apt update
sudo apt install samba samba-common-bin -y
```

- 配置文件 路径在<font color = blue>**/etc/samba/smb.conf**</font>

  ```bash
  [shared]
     path = /home/pi/shared   # 共享目录路径
     browseable = yes         # 是否可浏览
     writeable = yes          # 是否可写
     create mask = 0777       # 文件创建权限
     directory mask = 0777    # 文件夹创建权限
     public = yes             # 是否允许匿名访问
     guest ok = yes           # 允许访客登录
  #这里需要将上面的注释都删除或者注释放在单独的一行中
  ```

- 创建文件夹

  ```bash
  mkdir -p /home/pi/shared
  sudo chmod 777 /home/pi/shared
  ```

- 设置samba用户

  ```bash
  sudo smbpasswd -a pi #-a后面是用户名
  ```

  输入访问密码就好

- 验证配置文件语法

  ```bash
  testparm
  ```


<font color = purple font size = 5>**Windows中**</font>

两种方法

- 在凭据管理器中创建windows凭据

  - 然后在**计算机->映射网络驱动器** 中选择盘符，凭证，填写ip地址和路径

- 使用命令行

  ```bash
  net use Z: \\192.168.1.3\shared /user:pi xxxxx
  ```

  Z是选择的盘符，最后是用户(pi)和密码(xxxxx)
