常见的四类属性:

<font color = red>**分类的**</font>

- 标称
  - 与名称有关, 值是一些符号或者实物的名称, 每个值代表某种类别, 编码或状态(可以使用数字表示)

- 比率
  - 可以用比率来描述两个值, 即一个特征是另一个特征的多少倍. (例如开尔文温度, 字数, 工龄统计这些计数属性)

## 数据的相似性或者相异性

相似性

- 两个数据对象有多相似
- 值越大表示越相似
- 通常取值范围为[0,1]

相异性

- 度量两个数据对象的差别程度
- 值越小表示数据越相似
- 最小相异度为0

邻近性

- 相似度或者相异度

### <font color = blue font size = 5>**邻近性度量**</font>

**闵可夫斯基距离**
$$
d(i,j) = \sqrt[h]{|x_{i1}-x_{j1}|^h+...+|x_{ip}-x_{jp}|^h}
$$
性质

- 正定性$d(i,j) \ge 0, d(i,j)=0 \iff i=j$
- 对称性$d(i,j)=d(j,i)$
- 三角不等性: $d(i,j) \le d(i,k) +d(k,j)$

$h=1 $: 曼哈顿距离

$h=2$ : 欧氏距离

$h \to \infty$: 上确界距离
$$
d(i,j) = \lim _{h \to \infty} (\sum_{f=1}^p|x_{if}-x_{jf}|^h)^{\frac{1}{h}} = \max^{p}_{f}|x_{if}-x_{jf}|
$$
**余弦相似性**
$$
\text{sim}(d_1,d_2)=\cos(d_1,d_2) = \frac{d_1 \cdot  d_2}{\Vert d_1\Vert \Vert d_2 \Vert}
$$
当属性为二值属性时, 可以替换为公共属性个数和属性总数之间的比率
$$
\text{sim}(x,y)=\frac{x \cdot y}{x\cdot x+y \cdot y - x\cdot y}
$$

# 朴素贝叶斯分类

**分类的概念**

找出描述和区分数据类或概念的模型，以便能够使用模型预测类标号未知的对象的类标号。

**分类与回归**

- 分类：预测分类标号（离散的，无序的）

- 回归：建立连续值函数模型

**分类与聚类**

- 分类是有监督学习，提供类标签
- 聚类是无监督学习，不提供类别标签

## 极大后验假设

学习器在候选假设集合H中寻找给定数据D时可能性最大的假设h, h被成为极大后验假设（MAP）

确定map的方法是用贝叶斯公式计算每个候选假设的后验概率
$$
h_{map} = \max_{h \in H}P(h|D)=\max_{h \in H}P(D|h)P(h)
$$

$$
P(h|D) = \frac{P(D|h)P(h)}{P(D)}
$$

其中$P(h|D)$是后验概率，$P(D|h)$是先验概率

<center><font color = red><b>ps: 当数据维度过高时联合概率分布很难计算</b></font></center>

因此使用独立性假设

假设D的属性$a_i$之间全部互相独立

${P(<a_1,a_2,...,a_n>|h)=\prod_iP(a_i|h)P(h)}$
$$
h_{\text{MAP}}=\max_{h\in H} P(h| <a_1,...,a_p>)\\=\max_{h\in H}P(<a_1,...,a_p>|h)P(h)\\
=\max_{h \in H}\prod_i P(a_i|h)P(h)
$$
优点:

- 获得估计的$P(a_i|h)$比$P(<a_1,a_2,...,a_n>|h)$容易的多
- 如果D的属性之间不满足相互独立，朴素贝叶斯分类的结果是贝叶斯分类的近似

# 决策树分类

- 树状结构，可以很好的对数据进行分类
- 根节点到叶子节点每条路径对应一条规则
- 具有互斥且完备的特点，即每个样本均被且只能被一条路径所覆盖

# 基于规则的分类

<font color = red>**规则的质量**</font>

- 用覆盖率和准确率
  - 覆盖率：表示满足规则前件的记录的比例
  - 准确率：满足前件的记录中，满足规则后件的记录所占的比例

规则分类的特征

互斥规则集

- 每个记录最多被一个规则覆盖
- 如果规则都是相互独立的，分类器包含互斥规则

如果<font color = red>不互斥</font>

- 一个记录可能被多个规则触发

  解决方案：

<font size = 5 font color = blue>**有序规则集**</font>

根据规则的优先级将规则排序定秩，有序规则集又叫决策表，记录的类标签由最高优先级的规则决定，如果没有出发规则，定义为缺省

![image-20250102112901406](https://s2.loli.net/2025/01/02/6IcfFE4tKL5Tzvy.png)

- 基于规则的排序：根据规则的质量排序，即覆盖率和准确率，确保每个测试记录都是由覆盖它的最好的规则类分类，但是每个规则都假设排在它前面的规则不成立，规则量越大，解释后面的规则很麻烦。
- 基于类的序：将同一个类的规则放在一起，根据基于类信息（类的分布，重要性）对每类规则排序，缺点是容易导致高质量的规则被忽略。

![image-20250102112845367](https://s2.loli.net/2025/01/02/ACUKhLxw4eNaMdg.png)

<font color = blure font size = 5>**无序规则集**</font>

规则触发时记作一次投票，通过计算不同类的票数（可以加权）来决定记录的类所属

### 直接方法

基本思想

- 对每个类建立一个或多个规则
- 对第i类建立规则
  - 第i类记录为正例，其余为负例
  - 建立第i类的规则r, 尽可能覆盖正例，不覆盖负例（构建正例规则）
  - 删除r覆盖的所有记录，在剩余数据集上学习下一个规则, 直到所有第i类记录都被删除

![image-20250102113740014](https://s2.loli.net/2025/01/02/VrEsyG6tWA3oOUu.png)

删除正实例

- 防止高估后面规则的准确率
- 确保下一个规则不同

删除负实例

- 防止过拟合数据
- 防止低估后面规则的准确率

## 最小间隔面的推导

![image-20250102172322161](https://s2.loli.net/2025/01/02/NEh5HJS174lq3Qc.png)

这里对lagrange函数$L(\alpha,w,b)$中的$w,b$求偏导数带入到原函数中得到结果

![image-20250102172414219](https://s2.loli.net/2025/01/02/b7hgdAV8pyBcSnE.png)
$$
\begin{align*}
g(x) &= w^T x + b

\\
d_i &= \frac{|w^T x_i + b|}{\|w\|} = \frac{|g(w^T x_i + b)|}{\|w\|}
\\

找到使 (w^T x + b &= \pm 1) 的支持向量：
\\
d_{\min}& = \frac{2}{\|w\|}
\\

最大化超平面间隔：
\\
\max_{w,b} \frac{2}{|w|}

\\
&\text{subject to } \frac{w^T x_i + b}{\|w\|} \geq d, \quad i = 1, \dots, n

\\
等价于：
\\
&\min_{w,b} \frac{1}{2} \|w\|^2

\\
&\text{subject to } y_i(w^T x_i + b) \geq 1, \quad i = 1, \dots, n

\\

拉格朗日函数：
\\
L(w, b, \lambda) &= \frac{1}{2} \|w\|^2 + \sum_{i=1}^n \lambda_i \left(1 - y_i(w^T x_i + b)\right)

\\

\frac{\partial L}{\partial b} &= -\sum_{i=1}^n y_i \lambda_i = 0

\\
\frac{\partial L}{\partial w} &= w - \sum_{i=1}^n \lambda_i x_i y_i = 0

\\
得到：
\\
w &= \sum_{i=1}^n \lambda_i x_i y_i
\\

对偶形式：
\\
L(\lambda) &= \sum_{i=1}^n \lambda_i - \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \lambda_i \lambda_j x_i^T x_j y_i y_j
\\

最大化：
\\
&\max_{\lambda \geq 0} L(\lambda)


\end{align*}
$$

# 关联规则挖掘

## 关联分析

- 用于发现隐藏在大型数据集中的令人感兴趣的联系，所发现的模式通常用关联规则或频繁项集的形式表示
- 关联规则反应一个事物与其他事物之间的相互依存性和关联性。如果两个或者多个事物之间存在一定的关联关系，那么，其中一个事物发生就能预测与它相关联的其他事物的发生。

## 频繁项集

<font color = red>**项集**</font>

- 包含0个或多个项的集合
  - {milk, Bread, Diaper}

<font color = red>**支持度计数**</font>

- 包含特定项集的事务个数

  $\sigma (\{\text{Milk,Bread, Diaper}\})=2$

<font color = red>**支持度**</font>

- 包含项集的事务与总事务数的比值

<font color = red>**频繁项集**</font>

- 满足最小支持度阈值的所有项集

最大频繁项集：直接超集都不是频繁的

## 关联规则

$\{\text{Milk,Diaper}\} \to \{\text{Beer}\}$

支持度：整个项集的频繁程度

$s = \frac{\{\text{Milk,Diaper,Beer}\}}{|T|}$

置信度：后件在前件中出现的频繁程度

$c = \frac{\sigma(\text{Milk,Diaper,Beer})}{\sigma(\text{Milk,Diaper})}$

问题：发现并找出支持度大于等于minsup, 置信度大于等于minconf的所有规则，minsup和minconf是对应的支持度和置信度的阈值

- 频繁项集的产生
- 规则的产生：从上一步的频繁项集中提取高置信度的规则

## 划分方法

启发式方法

### k-means

- 随机选取k个样本作为初始中心
- 针对数据集中的每个样本$x_i$, 计算它到K个聚类中心的距离并将其分到距离最小的聚类中心对应的类中
- 针对每个类别$c_i$, 重新计算其聚类中心$c_i = \frac{1}{c_i}\sum_{x\in c_i}x$
- 重复前两个步骤，直到$\sum_{i=0}^n\min_{c_j \in C}(\Vert x_i-c_j \Vert^2)$

<font color =pink font size = 5>**优缺点:fallen_leaf:**</font>

优点

- 聚类时间快
- 结果簇是密集的，而簇和簇之间的区别明显时，效果好
- 相对可扩展和有效，能对大数据集进行高效划分

缺点

- 必须事先指定聚类个数
- 终止于局部最优
- 只能用于数值属性聚类
- 对噪声和异常数据敏感
- 不同的初始值不同结果
- 不适合发现非凸面形状的簇

### k-modes

- 使用众数代替均值
- 使用新的相异性度量
- 针对分类数据

<font size = 5 font color = blue>K均值和K中心点</font>

| 特性                 | K均值（K-Means）   | K中心点（K-Medoids） |
| -------------------- | ------------------ | -------------------- |
| **中心点类型**       | 簇的几何中心       | 簇内的实际数据点     |
| **适用数据类型**     | 数值型             | 数值型或分类数据     |
| **对异常值的敏感性** | 高                 | 低                   |
| **距离度量**         | 仅支持欧几里得距离 | 可用任意距离度量     |
| **计算复杂度**       | 较低               | 较高                 |

在实际应用中，如果数据集较大且相对干净，可以选择 **K均值**；如果异常值较多或需要更灵活的距离度量，可以选择 **K中心点**。

<font size = 5 font color = blue>随机森林</font>

- 模型的偏差是模型输出的期望, 这和模型本身的算法有关, 因此只和单个子树的性能有关系, 这和集成学习的准确率是有区别的
- 增加子树个数的原因在于降低方差(如果有无穷多个准确率大于0.5的子树, 那么输出正确的子树的数量肯定大于二分之一, 经过投票后最终的输出一定是1, 因此随机森林的准确率接近1)
- RF要降低子树之间的相关性



<font size = 5 font color = blue>类别不平衡</font>

- 过采样: 复制少量样本, 直到与多数样本数量相同(可能会导致过拟合)
- 欠采样: 从多数样本中采样, 知道与少数样本数量相同(可能会导致模型性能变差)



<font size = 5 font color = blue>缺失值处理</font>

1. 删除缺失值

- **删除缺失值所在的行**：如果缺失值较少，并且缺失的行对分析影响不大，可以直接删除。
- **删除缺失值所在的列**：如果某列的缺失值比例较高（如超过50%），可以考虑删除整列。

适用场景：

- 数据量充足，缺失值比例较低。
- 删除后不会显著影响分析结果。

优缺点：

- **优点**：简单直接，不引入额外误差。
- **缺点**：可能丢失重要信息，尤其是当缺失值占比大时。

**2. 填补缺失值**

1. **用统计值填充**：
   - 数值型数据：用**平均值**、**中位数**或**众数**填充。
   - 分类型数据：用**众数**填充。
2. **基于相邻值填充**：
   - 时间序列数据：用前一个值或后一个值（**前向填充/后向填充**）。
   - 插值法：使用线性插值、多项式插值等方法填充缺失值。
3. **基于分组的统计值填充**：
   - 按某个分类变量分组，用组内的统计值填充（如按地区分组，用各地区的均值填充）。
4. **预测填充**：
   - 使用机器学习模型（如回归、随机森林）预测缺失值并填充。
5. **随机填充**：
   - 基于变量的分布生成随机值填充。

适用场景：

- 缺失值比例中等，且数据特性允许推断。

优缺点：

- **优点**：保留数据的完整性，减少信息丢失。
- **缺点**：可能引入偏差或误差，尤其是预测填充可能过拟合。

**3. 保留缺失值作为特殊值**

方法：

- 为缺失值单独创建一个类别，例如填充为“缺失”或“未知”。
- 使用标志变量记录缺失值的位置，作为模型的一个特征。

适用场景：

- 缺失值可能具有实际意义（例如，“未回答”可能表示拒绝回答）。
- 模型能有效利用标志变量处理缺失值。

优缺点：

- **优点**：不引入误差，适用于分类问题。
- **缺点**：对一些模型（如线性回归）可能不适用。

**4. 插值或推测缺失模式**

 方法：

- **多重插补**：通过构建多个插补数据集，评估填补缺失值的不确定性。
- **EM算法**：通过期望最大化估计数据分布，推测缺失值。

适用场景：

- 缺失值有一定模式，并且比例较高。

优缺点：

- **优点**：更精确，能反映数据的不确定性。
- **缺点**：计算复杂，依赖模型假设。

 **5. 不处理（作为特殊处理策略）**

 方法：

- 在模型或算法中直接处理缺失值（例如，某些决策树算法能直接处理缺失值）。

适用场景：

- 使用支持缺失值的算法（如 XGBoost、LightGBM）。

优缺点：

- **优点**：简单，直接利用算法的内置机制。
- **缺点**：对其他算法不可行。

<font size = 5 font color = blue>模型评价</font>

- 欠拟合: 模型复杂度低, 不能很好拟合所有数据; 增加模型复杂度, 引入更多特征；训练集过大，模型过于简单
- 过拟合: 模型复杂度高, 测试误差大; 降低模型复杂度, 引入正则化, 增加训练数据
- 准确率: 正例和负例都预测对
- 召回率(TPR)
- 精确率(查准率): 在预测为正例的样本中正例的个数
